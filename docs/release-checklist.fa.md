# چک‌لیست انتشار فرانت‌اند کتابسرای پردیس

## پیش‌نیاز محیط

- از Node `22.13+` (یا `20.19+`) استفاده کنید؛ نسخهٔ پیشنهادی در `.nvmrc` ثبت شده است.
- متغیر یا reverse proxy مربوط به `/api` باید API را به backend متصل کند.
- برای React Router باید در وب‌سرور، همهٔ مسیرهای غیر API به `index.html` بازگردند.

## بررسی پیش از انتشار

```powershell
npm ci
npm run typecheck
npm run lint
npm run build
```

## مسیرهای حساس برای تست دستی

- ورود OTP، ورود با سبد مهمان و تکمیل پروفایل
- فیلتر کاتالوگ، جزئیات SKU و افزودن به سبد
- نشانی، پیش‌فاکتور، ساخت سفارش و بازگشت از درگاه
- سفارش‌ها، تیکت پشتیبانی و خروج از حساب

## نکتهٔ پرداخت

نشانی بازگشت درگاه باید در allowlist backend قرار داشته باشد. نتیجهٔ پرداخت شناسهٔ تلاش پرداخت را در session نگه می‌دارد تا اگر درگاه query parameter را بازنگرداند، امکان استعلام و تأیید وضعیت حفظ شود.
